# 先分清窗口、地址与令牌

[返回首页](../README.md)

先把几个名字分清楚，后面的操作会轻松很多。不要把一章中所有代码不看说明地一次性粘贴。

## 三个操作位置

| 本文标记 | 你通常看到的提示符 | 在哪里 |
| --- | --- | --- |
| VPS 终端 | `ubuntu@服务器名:~$` | 腾讯云或其他云厂商 WebShell / SSH |
| Windows PowerShell | `PS C:\Users\你的用户名>` | 电脑上的 PowerShell |
| 糯叽机 | 聊天输入框或 MCP 配置页 | 手机或电脑客户端 |

`sudo`、`systemctl`、`journalctl` 是本教程的 Linux 服务器命令。把它们输到 Windows 后提示找不到命令，不代表服务器坏了，也不需要去开启 Windows 的 Sudo。

`C:\...` 是电脑路径，`/home/ubuntu/...` 是服务器路径。网页文件管理器里看见的文件通常位于服务器，并不等于已经下载到电脑。

## 三个公网地址和三个内部端口

本教程统一用 **`mcp.example.com`** 作为占位域名。必须换成你实际拥有并已解析到 VPS 的域名，不要真的访问这个示例域名。

| 谁使用 | 地址示例 | Caddy转发到 |
| --- | --- | --- |
| StackChan 长连接 | `wss://mcp.example.com/` | `127.0.0.1:8765` |
| StackChan 照片上传 | `https://mcp.example.com/capture` | `127.0.0.1:8766` |
| 糯叽机 MCP 客户端 | `https://mcp.example.com/mcp` | `127.0.0.1:8767` |

完整示例：假设你拥有并已配置好 `1234.com`，设备地址就是 `wss://1234.com/`，糯叽机地址是 `https://1234.com/mcp`，上传地址是 `https://1234.com/capture`。若使用子域名，三处要一致，例如 `mcp.1234.com`。协议写 `wss`，不是 `wws`；不要只填没有后缀的“1234”，也不要实际使用别人的示例域名。

三个地址属于同一套服务，但用途不同。`/capture` 是设备把照片发给 VPS 的入口，不是视觉模型地址。只看到 MCP 已连接，不代表相机上传必然也成功。

远程设备访问不了 VPS 的 `127.0.0.1`；但 Caddy 和网关在同一台 VPS 时，反向代理访问内部 `127.0.0.1` 是正确的。

## 三种令牌不要混

- `STACKCHAN_TOKEN`：StackChan、VPS 网关及本例糯叽机 MCP 认证使用的共同令牌。它是你自己生成的随机字符串。
- 网关 `VISION_TOKEN`：可选的照片上传令牌；本路线留空，网关复用 `STACKCHAN_TOKEN`。
- 外部模型 API Key：只有备用外部识图路线需要，与前两个令牌不是一回事。

备用外部识图使用独立的私有配置文件保存API地址、模型名和API Key；它与网关的 `VISION_URL` 上传地址不是同一项配置。推荐直接传图路线不需要额外填写识图API配置。

专用“令牌”输入框通常只填令牌本身；只有自行填写 HTTP 请求头时才使用 `Authorization: Bearer 令牌`。以当前客户端字段说明为准。

密钥只在你自己的服务器或客户端配置，不发给 AI、不写进教程、不提交 GitHub。排错时把令牌、手机号、个人域名或带认证的URL按需脱敏。

## 先备份再修改

已有服务能用，就先记下服务名、配置位置及版本。不要靠重装排错；升级 Python 包可能覆盖本教程直接改在安装目录中的扩展。

服务器备份目录需要保留到验证结束。固件更新前也要备份设备 Flash。下文涉及服务重启、设备重启和刷机时，会单独标注。

## 怎么判断“成功”

- `active`：说明服务进程正在运行，不等于设备已经连上。
- `ESP32 ready`：说明设备和网关完成会话初始化，不等于客户端已收到图片。
- 黄色默认脸或“待命”：说明界面或状态在运行，不能单独证明公网 MCP 链路正常。
- 糯叽机调用MCP工具卡片绿勾：说明调用完成并返回了内容，还要检查里面是否 `ok: false`、`error` 或其他失败信息。
- 直接看图：应有 MCP 图片返回，且角色能描述新拍画面的具体内容；只有照片文件路径还不够。
