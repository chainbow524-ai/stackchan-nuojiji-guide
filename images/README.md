# 效果图准备

本地初稿不直接复制聊天截图或头像素材。正式公开前可挑选并脱敏以下图片：

1. 自定义头像与字幕同时可见的设备照片。
2. 拍照预览显示在头像上方的设备照片。
3. take_photo返回MCP图片，以及聊天模型描述实际物品的客户端截图。
4. WebShell和Windows PowerShell提示符对比，帮助新手分清窗口。
5. 自动眨眼演示，注明连接成功后开启，不宣传成断网也从第一秒生效。

裁去或遮住个人号码、聊天对象信息、令牌、私有域名、设备标识和私人画面。第三方界面及角色图案不因截图自动成为本教程原创素材。

本页只是配图建议，没有损坏的图片占位链接，也没有把私人截图上传到外部服务。
