# StackChan 接入糯叽机新手教程

教程整理与实测：**浅默** · 初稿日期：2026年10月24日

AI协作：**ChatGPT / Codex**（教程编写、代码修改与排错协助）。

让桌上的 StackChan 小机器人接入糯叽机：角色能拍照看东西、在屏幕上显示文字、切换冷脸表情，以及在连接成功后自动眨眼。

本教程由个人操作记录整理，AI 编程助手协助编写和排错，是基于上游项目的使用与修改教程，不是 M5Stack、糯叽机或上游作者的官方说明。

**先看这一条：目前已经实测 `take_photo` 直接把图片返回给糯叽机，支持看图的聊天模型可以据此回答。不必为主路线另买一个识图 API。** 原来的“拍照＋外部模型识图”保留为可选备用。

## 能实现什么

| 功能 | 使用方式 | 本次验证范围 |
| --- | --- | --- |
| 拍照直接看图 | `take_photo(question)` | 图片以 MCP 图片内容返回，角色读出瓶子品牌、标签颜色和容量；个人环境已验证 |
| 屏幕字幕 | `show_text(text)` | 原有自定义冷脸保留，字幕显示在其上方；个人修改版已验证 |
| 拍照预览 | 拍照时由固件显示 | 预览显示时提到前景，保留原有大小及约5秒时长；个人修改版已验证 |
| 六种表情 | `set_avatar(face)` | 参数为 idle、happy、thinking、sad、surprised、embarrassed；具体效果取决于所装素材 |
| 自动眨眼 | `set_blink(enabled)` | 开启后随机约3～6秒眨眼；网关恢复默认头像后自动开启已验证 |
| 头部动作和亮度 | 对应 MCP 工具 | 工具在本版本中存在，本文不把所有动作与范围都标为已实测 |
| 可选外部识图 | `take_photo_and_analyze(question)` | 一次调用内部完成新拍照与外部识图，返回文字；旧方案已验证，本仓库独立版待VPS复测 |

本文不配置机器人扬声器说话。人设里的屏幕字幕明确使用 `show_text`，不要调用 `say`。

## 先确认自己适合哪条路线

- **从未部署过：**先读准备材料和基础部署章。这一版给出了参考部署步骤，但全新服务器、全新设备的完整组合尚未独立端到端复测。
- **只有字幕或预览被冷脸盖住：**只读固件显示修复章。其他功能正常时不要清空设置。
- **想让待命时自动眨眼：**只读自动眨眼章；这项可以改 VPS，不用刷机。

## 准备材料

| 材料 | 用途 |
| --- | --- |
| M5Stack 官方 StackChan / CoreS3 对应硬件 | 个人设备为 ESP32-S3、16MB Flash、8MB Quad PSRAM、GC0308 相机；其他硬件不要照抄刷机地址 |
| 可联网的2.4GHz Wi-Fi或手机热点 | 供设备访问公网网关。手机上的 VPN 不等于热点设备自动使用 VPN |
| Windows 电脑和 USB 数据线 | 读取日志、备份及必要的固件更新；日常使用不必始终接电脑 |
| Ubuntu VPS及一个自己控制的域名 | 运行网关，提供 HTTPS/WSS 入口；已有网站的服务器要保留现有配置 |
| 糯叽机及支持工具调用、图片输入的聊天模型 | 接收并识别MCP 工具图片。 |
| 可登录 VPS 的终端和上传工具 | 云厂商 WebShell 等均可，不要求特定品牌工具 |

个人实测使用外区VPS，所在地区为东京，配置为2核CPU、2GB内存、40GB系统盘，Ubuntu 24.04。这里只记录实测环境，不推荐具体国家或地区，也不是最低配置承诺。中国大陆地区的VPS尚未实测，不能确保按本教程一定部署成功，需自行验证网络和服务可达性。服务器、域名、聊天模型可能分别计费；直接看图的图片输入也可能计入当前聊天模型费用。

## 版本与实测边界

个人网关版本为 `stackchan-mcp 0.18.0`，应用固件显示 `2.2.6`，编译环境为 `espressif/idf:v5.5.2`。这三个版本号不是同一个东西。个人已安装外部识图扩展后显示53个客户端工具；设备日志出现44个设备工具，二者不是同一份列表。

同样显示2.2.6的两份固件，也可能包含不同提交、不同配置和素材。下载源码时请记录所用版本和子模块版本，方便以后更新、复现及排错。

依据是2026年10月9日至24日的个人部署和实测记录。新用户完整部署、各云厂商控制台界面、所有型号与网络环境尚未逐一验证。请以当前步骤的检查结果为准；遇到未预期输出就先停下，不跨过失败继续运行。
